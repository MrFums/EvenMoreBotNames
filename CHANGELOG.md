# Changelog

## 1.1.0

- `UsecNamesToLoad` and `BearNamesToLoad` now load the same names on every start instead of a new random set. Mods that make a profile per name, like PBT, no longer redo it on every start.
- Raising either number keeps the names you already had and adds more.
- New `NameSeed` option. Change it to pick a different set of names.
