# Even More Bot Names

Gives PMC bots and flea sellers 300,000 USEC and 300,000 BEAR names that look like real player names.

For SPT 4.1.

## Install

Put the `EvenMoreBotNames` folder in `SPT/user/mods`.

## Config

`configs/config.jsonc`. Set `UsecNamesToLoad` and `BearNamesToLoad` lower to use less RAM. The same number loads the same names every start.

## PBT

PBT makes a profile for every name, so the first start after installing takes a while. Later starts are fast as long as the name settings stay the same. Before 1.1.0 this mod picked new names every start, so PBT's data may be full of old names. Delete PBT's `Data` folder once after updating to clear them.
