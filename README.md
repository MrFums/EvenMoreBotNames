# Even More Bot Names

Gives PMC bots and flea sellers 300,000 USEC and 300,000 BEAR names that look like real player names.

For SPT 4.1.

## Install

Put the `EvenMoreBotNames` folder in `SPT/user/mods`.

## Config

`configs/config.jsonc`. Set `UsecNamesToLoad` and `BearNamesToLoad` lower to use less RAM.
